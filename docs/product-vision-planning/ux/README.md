# UX planning artifacts

These are low-fidelity planning wireframes produced by `/peak-workflow:mockup` for the gateway's
usage dashboard. Open `wireframes/index.html` in a browser (no server needed) for a clickable list
of every screen, then use the state buttons on each screen to switch loading / empty / error /
populated. They are grayscale on purpose — visual design happens in the walking-skeleton epic.
`screens.md` is the inventory (app shell, screens, states, flows), and the Concept of Operations
references screens by their `S-NN` IDs.
